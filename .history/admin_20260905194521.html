Categories

Categories are the filter tabs visitors see at the top of the gallery. The all category is built-in and cannot be deleted. Each item must reference one of these category IDs.

Publish to GitHub

How this works: Publishing writes a gallery-config.json file to your GitHub repo. The live site fetches this file (cache-busted) and uses it instead of the baked-in defaults. All visitors see your changes after a refresh.
Create one at github.com/settings/tokens with the repo scope. Stored in your browser only (localStorage).

How visitors get your updates

  1. You edit items/categories here → they save instantly to your browser (localStorage).
  2. You click Publish to GitHub → the config file is committed to your repo.
  3. Visitors load (or refresh) the live site → gallery.js fetches gallery-config.json with cache-busting and uses it.
  4. If the fetch 404s (e.g., you haven't published yet), the site falls back to the baked-in defaults — nothing breaks.

Note: New media files (videos, images) still need to be uploaded to the repo separately (via GitHub web UI or git push). The admin panel only manages the metadata — title, category, file path, etc. — not the binary files themselves.

Backup & export

Your current config (items + categories) is stored in your browser's localStorage. Export it as a JSON file for backup, or to move it to another browser.
